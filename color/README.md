# CSS Colors

Colors are taken from the original 216 "web safe" colors. The directory names are those given to each color in the CSS3 Color Specification.

Many colors are inherently light or dark, so lightening or darkening may result in defaulting to white or black, respectively. But all such variables, properties, and classes are included for completion, though they will likely not be used.

For example, Light Rose - #ffcccc - is very pale; very nearly white. So lightening this color converts to white at a mere 10%. Yet Light Rose lightened from 10% through 100% are included.
