# Rebeccapurple

This is an alias of Amethyst (#663399). It was officially added to CSS in 2014, to honor the daughter of CSS pioneer Eric Meyer after her untimely death. It is included here for the same reason.

Link: [https://lists.w3.org/Archives/Public/www-style/2014Jun/0312.html](https://lists.w3.org/Archives/Public/www-style/2014Jun/0312.html)
